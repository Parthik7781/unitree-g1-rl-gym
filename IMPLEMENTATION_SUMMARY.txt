KEY INNOVATIONS
================================================================================

1. HILBERT TRANSFORM FOR PHASE DETECTION
   - Accurately detects 180° phase shift
   - Works with noisy IMU data
   - More reliable than cross-correlation
   - Directly measures instantaneous phase

2. MULTI-LEVEL FILTERING STRATEGY
   - Low-pass: Reduces sensor noise
   - Integration: Computes velocity, then position
   - High-pass: Removes gravity drift
   - Detrending: Removes low-frequency artifacts
   - Result: Clean, meaningful trajectories

3. BILATERAL SYMMETRY METRICS
   - Measures movement range symmetry
   - Detects imbalances between legs
   - Useful for identifying strength imbalances
   - Complementary to phase information

4. TEAR-DROP PATTERN VISUALIZATION
   - Intuitive visual representation of gait
   - Research-quality publication-ready plots
   - Easy interpretation of gait quality
   - Supports both individual and bilateral views

MATHEMATICAL DETAILS
================================================================================

PHASE SHIFT CALCULATION:

  Input: Gyroscope signals (pitch - Gy)
  
  Step 1: Hilbert Transform
    z(n) = x(n) + j·H[x(n)]
  
  Step 2: Instantaneous Phase
    φ(n) = atan2(Im(z), Re(z))
    φ_unwrap(n) = remove 2π jumps
  
  Step 3: Phase Difference
    Δφ = mean(φ_right - φ_left)
  
  Step 4: Convert to Degrees
    Phase_deg = Δφ × 180/π
  
  Normalization: Δφ → [-180°, 180°]
  
  Formula: phase_deg = (time_lag / gait_cycle_time) × 360°

TRAJECTORY CALCULATION:

  Input: Accelerometer signals (ax, ay)
  
  Step 1: Low-pass filter
    a_filtered = Gaussian_filter(a, σ=2)
  
  Step 2: Integration (cumtrapz)
    v = ∫ a·dt
  
  Step 3: High-pass filter
    v_filtered = Butterworth_HP(v, fc=0.5 Hz)
  
  Step 4: Integration (cumtrapz)
    x = ∫ v·dt
  
  Step 5: Detrending
    x_final = detrend(x)

SYMMETRY CALCULATION:

  X_range_L = max(X_left) - min(X_left)
  X_range_R = max(X_right) - min(X_right)
  
  Symmetry_X = 1 - |X_range_L - X_range_R| / max(X_range_L, X_range_R)
  
  Similarly for Y...
  
  Overall_Symmetry = (Symmetry_X + Symmetry_Y) / 2
